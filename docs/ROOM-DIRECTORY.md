# 公开同盟大厅与房间简介

本次改动已于2026年10月9日发布到线上r19（`f98635fe1af8-10`）。r16、r17按用户要求关闭，保留r18进行中的旧对局及r19新版。

## 玩家操作

- 大厅压缩模拟方式与密钥加入区域，新增公开房间列表和独立的同盟招募列表。
- 创建同盟时填写必填简介（最多120字），并明确选择公开或私有；5～8人先确认测试提醒，再填写简介和选择公开方式。
- 公开房间自动进入房间列表。房主点击“发布招募”，直接发布已保存的简介，每次间隔10秒。
- 房主可修改简介；已发布的招募同步更新文字，但不刷新排序时间或冷却。满员或进行中的房间不展示招募，私有会撤下招募，结束后可重新发布。
- 私有房间继续支持密钥、邀请链接、房间聊天；房间设置仅房主可修改。
- 复制密钥仍只复制密钥。复制链接按行包含有效邀请链接、邀请语、最新简介、容量、棋盘版本和密钥，整段粘贴仍可识别房间。
- 保留在线／匹配中／对局中人数、问题反馈群561101140、干员调配、自选编队。移除新客户端大厅快速匹配与房间组队匹配入口，旧版匹配接口保留兼容。

## 棋盘外观（以用户两张参考图为准）

`classic` 对应“0.1.4经典棋盘”：原材质、灰色地面、立体边缘，使用现有three.js场景与本地提取的棋盘素材。无法启用3D时保留材质棋盘回退。

`new` 对应“新版简约棋盘”：当前简化格子，使用现有Pixi程序化棋盘，不加载经典棋盘贴图及three.js。两种选择共用地图地形、路线和战斗规则，不恢复旧版本数值。

房间外观在创建对局时写入Match的公开状态，进入、观战、重连采用该对局的选择。恢复的`data/local-assets.json`只加入本地已有的74项地图／模型条目，其他角色清单没有改写。

## 同步与界面

房间目录仅返回公开房间摘要，不发送聊天历史、会话令牌或完整战斗状态。目录编码缓存1秒，房间变化立即失效；大厅可见时每5秒刷新，游戏内不轮询，刷新受服务器重响应限流保护。

10秒招募冷却由服务端判断，切换公私、重连、换房主均不能清零。

手机保持横屏和双栏大厅。密钥／邀请复制入口始终显示；8人席位在自身区域滚动，房间聊天使用紧凑栏与历史弹窗。战斗内已有可拖动聊天框保留。

## 验证

`tools/qa-room-directory.mjs`使用真实本地WebSocket服务与两个独立Edge浏览器身份，验证创建、简介发布／编辑、公开与私有切换、双端聊天、邀请分享、粘贴识别和8人警告顺序。检查844×390、932×430、667×375、640×360的按钮可见性及命中区域，并验证8人下排滚动后可添加AI。

剪贴板在浏览器测试中替换为记录器，验证按钮和复制内容；没有访问系统剪贴板，也没有宣称测试真实安卓／iOS系统剪贴板。

`tools/qa-room-board.mjs`逐张渲染数据中的13个地图记录（8张启用地图、5个未启用或特殊记录），分别检查经典和简约外观在普通、联防、首领视角下的78种组合。记录启用状态，检查实际地图ID、材质／3D模式、相机参数及两种外观的地形和高度一致，并为每张地图输出对照截图；另外检查经典回退与新版不下载经典贴图／three.js。检查未启用记录不改变它们的启用状态。软件GPU上的性能数字不能代表玩家设备性能。

本地截图与报告保存于工作区`outputs/public-room-lobby`，相关服务端、渲染和客户端测试见`final-regression-tests.log`。

## 上线验证

服务器从r18隔离复制，仅覆盖本次功能文件，保留原有游戏数值与同步优化。服务器隔离测试6项通过；本地相关回归505项通过。正式HTTPS入口经两个独立浏览器身份验证公私切换、列表显示、私有邀请、聊天、手机复制按钮命中及分享内容；测试房间已移除。

新版继续使用12,881项R2资源映射；恢复的74项棋盘资源与腾讯静态镜像逐项校验一致。真实浏览器经新版Service Worker读取经典棋盘资源，返回`x-sp-resource-source: r2`，大小和SHA-256与清单一致。上线前后r18工作进程PID及源文件保持一致，已有在线对局继续运行。

部署记录、正式手机截图及验证结果保存在`outputs/lobby-r19-deploy`。
