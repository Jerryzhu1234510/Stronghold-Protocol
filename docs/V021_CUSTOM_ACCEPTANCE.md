# v0.2.1 定制整合验收

本包实际合并官方 v0.2.1 源码和数据，官方版本提交为 c2a2ef778cf728ff29b953b9842b2a39b1e9cbea。已逐文件核对下载源码与 GitHub 标签，仅四个 Windows 启动文件存在换行符差异。package.json、package-lock.json、shared/constants.js 均为 0.2.1。

官方更新见 https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.2.1 。包含满潜能、恢复联防地形、双人战场突袭跨半场、装备满栏替换、Touch 范围、凋亡扣技力、贾维策略奖励时机、器物击打次数和领袖召唤物回合加成、自选盟约详情、飞行高度与敌人动画、加载期间接管及强制结束消息处理。

保留自定义内容：5～8人卡池和生命加成、5人以上干员属性加成、多人数敌方难度、商店倾向和额外格、减少禁用、有限重复开局、个人自选库存及晋升奖励、整队匹配、房间聊天、两位联动干员、结城理形态及动画修复、反馈群置顶、滚动公告、延迟诊断和热更入口。冻结与刷新保持原布局，盟约倾向为右上角小型控件。

联防：四人及以下采用官方0.2.1本回合地形，5～6人双人联防，7～8人三人联防、传送门及1.6倍倒计时。多人首领使用真实生产血量测试入场，快速击杀流程测试仅在测试内降低首领血量，不代表长期实战平衡保证。

两位联动干员的全部训练形态使用0.2.1官方生成器重新计算满潜能，兼容记录及custom-overlay.json同步更新。所有262个训练形态的原始属性和潜能加成逐一核对通过。

本轮测试：干员与战斗内容2062项通过；满潜能、多人平衡、奖励、结城理形态等97项通过；多人房间、联防各地图、5～8人首领、自选、加载消息、渲染、界面和热更入口等250项通过。套件有交集，不将其相加宣称为不重复测试数。导入边界和冲突检查通过。旧版历史验收记录见V020_CUSTOM_ACCEPTANCE.md，不以其“尚未合并0.2.1”的历史说明作为本包状态。

服务器首次迁移需安排维护，等待旧对局结束；以后通过update启动独立新版，已开始的旧局继续旧版，结算返回大厅后刷新新版。重启容器或机器仍会中断对局，启动记录仅保存当前版本目录。本包未在腾讯安装，未验证200人并发。
