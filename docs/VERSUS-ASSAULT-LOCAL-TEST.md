# 四人攻守对抗（测试版）

2026-10-12 已以 r27（`83270655cd7a-18`）发布到正式服务器，模式仍标记为测试版。发布与安全清理记录见 `PRODUCTION-R27-20261012.md`；下方保留本地规则及验收记录。

## 入口

进入大厅，创建同盟房间，在原房间的模式选项选择“对抗模式（测试）”，默认难度同步设为“绝境模拟”。直接创建对抗房间也使用这个默认值；之后仍可由房主修改难度。房间固定四人；本地验收可以添加三个 AI。保留禁用盟约确认页，跳过策略选择。

## 比赛

- 四人分成两组一对一，半决赛后两位胜者进入决赛，选出一位冠军。
- 每组先一攻一守，每段最多八分钟；蓝门提前失守立即交换，不必等满八分钟。
- 交换后有二十秒整备，仅影响本组，另一组继续比赛。
- 双方各守一次后依次比较：漏怪较少、守住时长较长、击杀怪物价值较高。三项完全相同则抽签，结算明确显示。
- 两位半决赛败者并列第三。认输、退出直接判该组落败，不强制留在观战。

## 商店和操作

- 守方直接使用原版 ShopBar、干员卡和装备栏；攻方使用同一商店框架，仅出售怪物。
- 商店每级扩容：3/4/5/6/8/10 个干员或怪物位，守方另有 1 个装备位，总计最高 11 位；升本保留现有卡牌及已售出格，只增加新格，不免费刷新整店。
- 原版两次点击购买、详情、朝向轮盘、拖动控制器、撤回/出售框、装备替换窗口和三合一奖励复用。
- 攻守金币、库存和商店等级分开保存；晋级决赛清空角色银行、库存、干员和装备，重置为 20 金币、1 本。
- 每段前四分钟每两秒一金币，之后每秒一金币；守方击杀敌方投放怪物每只一金币，攻方每击倒守方干员或每次漏怪造成蓝门扣血获得五金币（不按扣血点数重复计）。金币上限一百；盟约上限二百层。
- 升本费用 10/18/28/40/55，两次升本至少间隔二十秒；守方升到三/四/五/六本需要部署二/三/四/四名干员。攻方不受干员数量限制。
- 一至三本怪物每包两只、四本起每包一只；一次投放整包。源石虫整包三金币，其余前期怪物在此前价基础上打七折向下取整，最低两金币；高阶价格保留此前方案。次数怪的衍生物不单卖，仍由原父怪技能生成。
- 每段前两分钟怪物生命与攻击为 70%，之后恢复正常并持续增强，两项均封顶两倍。战斗模拟二倍速，八分钟倒计时、被动收入和三十秒特质窗口仍按真实时间。
- 双方默认使用守方战场视角，投怪区前压到守方最靠近中线的两列。拖动干员回备战区直接撤退，移动后当次选择朝向，保留生命和技力；场上与备战区都显示已装备图标。
- 对抗模式飞机及其飞行衍生物复用原地面流场寻路，绕行地形后到达蓝门，路线预览保持一致；仍保留飞行单位的对空和阻挡判定。正常模式的飞机直线路线不变。
- 购买、售出、刷新、升本、装备使用原版音效；攻击只使用原有单位音效，原版没有就保持静音，不添加通用替代。
- 原 Boss 地图与简约版、0.1.4 棋盘外观保留。点击头像可观战其他玩家，手动“大地图”可看本组全图。
- 手机局部视角通常保留单格缩放三十六至六十像素；极矮屏或手动展开盟约时，复用原版 HUD 避让算法，只在后排人物与备战格不能同时放下时缩小。盟约移回正常模式左上原位，复用原版收起按钮、激活圆盘与透明点击区域；手机默认收起。展开时按实际高度避让后排人物，长列表横向查看，不额外占用商店上方一行；无成员不留空白盟约框。大地图完整适配战场；部署、投怪不自动切换大地图。整备时允许同时间快照更新，后部署干员不再被渲染端丢弃。
- 剩余购买、刷新、消费、复合条件和赠送类特质按三十秒窗口结算，沿用原版服务端处理器；详情显示新触发条件。简单加层和金币特质仍按击杀触发。
- 右上工具栏增加原版样式规则按钮，打开测试版完整规则。点击场上干员或怪物显示原版实时面板，属性随战斗更新，不再只有基础记录；对方单位详情为只读。
- 对抗阿戈尔不吞噬：保留原生命加成，每层额外增加 0.5% 攻击和生命，即时生效；每名在场成员每五秒加一层，多人独立触发，按真实时间计算，倒地或撤回重置计时，上限二百层。五名不同成员前三名首次倒地立即复活保留。正常模式的吞噬不改。
- 克莱门莎二技能水囊终点增加持续旋转的水蓝色旋涡，范围与伤害区一致，持续两秒模拟时间（二倍速下一秒真实时间），不再按每个受击敌人重复叠爆炸。
