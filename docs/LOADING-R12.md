# r12 加载修复

2026-10-08 腾讯线上：约 250 个连接，10 秒出口平均约 57 Mbps。可用内存约 2 GB、swap 为零；游戏进程事件循环正常，无快照队列积压。冷启动实测大厅 13.3 秒，干员等静态数据再耗时 9.4 秒；重复打开仍重复下载棋子、补位等数据。单客户端 128 KiB/s 的后台预下载并不限制全服务器总量，也没有真正限制每次下载的瞬时速度，多玩家叠加会争抢带宽。

- 暂停默认全量预下载；正常使用到的素材继续按内容哈希保存和跨版本复用，已有缓存不清空。
- 缓存 worker 将旧 r11 自动 warm 消息置为 paused；显式 manual 消息保留受控下载接口，暂未开放 UI。
- 游戏数据仅在版本固定的生产页面使用 HTTP 缓存；开发页面继续重新验证。
- Caddy 仅对版本路径下的静态 data/*.json 设置 immutable。健康检查、对局、WebSocket、统计接口不缓存。
- 线上 Caddy 向 r11 worker 地址提供暂停预下载的兼容修复，浏览器检查 worker 更新后生效。r12 大厅入口热更，老对局继续留在原版本。
- 补充修复：网关改写静态文件时混用了 `cache-control` 和 `Cache-Control`，实际响应带两行冲突缓存头，`no-cache` 使脚本和 CSS 在每次进入时重新下载。网关源码统一使用小写；线上通过 Caddy 替换固定版本的静态响应头即时修正，排除 worker、HTML 和实时 API。
- 对启动必需的模块增加 modulepreload，避免逐层发现依赖；未预下载整套游戏资源。当前 Caddy 页面提供这些入口优化，未来打包需运行 `node tools/build-startup-preloads.mjs`。
- 旧 r11 调度器不认识 paused，因此兼容 worker 对自动 warm 返回 complete，避免 100 ms 轮询。此值仅表示停止预下载调度，不能作为资源全量下载完成的依据。

线上浏览器验证（2026-10-08；桌面及手机尺寸的 Edge，无真实手机硬件性能承诺）：测试房间创建 184/254 ms，PREP 阶段重连回原房间 767/952 ms，商店干员名称及立绘正常，无脚本错误，素材缓存 HIT。修正响应头后的重复进入，脚本、字体及数据传输量为 0；静态数据载入约 64 ms。首次打开仍测到约 22.6 秒，缓存后的大厅约 5.6 秒，因此尚不能声称首次访问慢或所有网络卡顿已解决。

验证：自动 warm 不产生资源下载；按需素材缓存仍命中；版本变化且素材相同仍复用；数据缓存只在固定版本启用。线上另测冷/热打开、房间创建和重连。服务器带宽及客户端渲染卡顿需要分别测量，不能据此承诺所有卡顿消失。
