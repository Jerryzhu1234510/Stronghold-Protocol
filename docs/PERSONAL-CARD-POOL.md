# 个人卡池

房主在开局前打开“房间扩展设置 → 个人卡池”。默认关闭；关闭时沿用共用卡池。

开启后，每位玩家和AI各自拥有一份完整干员卡池。商店刷新、盟约倾向、合成奖励、机变及策略赠送使用本人的库存；购买、晋升、出售、销毁、临时区清理和淘汰回收只影响本人。原有禁用盟约、房间人数／克隆数量倍率、抽取权重及已显示卡片允许透支的规则保留，这不是无限卡池。

自选干员仍使用本人的自选库存。AI不再因队友使用同一核心盟约而躲避该阵容。修改设置后全员重新准备，开局后锁定；重连继续使用本局设定。

按照既有计杯规则，个人卡池属于自定义局：正常4～8人终极通关从8杯改为4杯；与克隆、取消Boss限伤或鸭爵加强组合时只减半一次。仅提高敌人生命的普通局仍然不减杯。

只需更新服务器代码和随服务器发布的网页程序。PC1.0.8和安卓1.0.3原生壳无需因这个选项重装；资源包没有新增内容。玩家须重新进入新版本，进行中的旧局不会改变规则。安卓之前的资源读取修复仍需要升级1.0.3，和本选项是两件事。

本地已覆盖4／8人、普通／克隆、库存透支、奖励、出售与淘汰、AI六轮流程、自选库存以及计杯测试。界面在Edge模拟电脑、平板和手机尺寸验证；这不代表真实iOS或安卓设备验收。
