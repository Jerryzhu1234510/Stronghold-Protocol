# r11 自动素材预下载与表情修复

腾讯版已于 2026-10-08 热更启用，当前代号 `982817cd818c-2`，目录 `/releases/r11`。
旧 r10 进程和当时 199 个连接保留；没有重启容器。

页面启动后随机等待 5–15 秒，自动向 Service Worker 请求单文件预下载。
按内容哈希去重；小图片优先、音频最后；平均预下载预算 128 KiB/s，单文件最多等待 8 秒。
已缓存素材直接复用，跨热更版本不重复保存。战斗、断线及显示延迟超过 200 ms 时暂停，存储失败退避重试。
默认开启，可在设置查看进度；浏览器禁用缓存、非安全来源、空间不足或关闭/挂起网页时无法强制执行。
这是磁盘缓存，不提前解码全部模型、图片或音频到内存。首次下载占用带宽，后续缓存命中才减少服务器下载压力。

5–8 人滚动列表曾裁掉头像右侧表情气泡；气泡现在在列表内部显示，并保留收到消息的时间。
发送失败会提示错误，避免静默失败。

验证：缓存/表情纯逻辑 35 项，32 通过、3 因缺少本地素材清单跳过；针对实际点击、触屏和 8 人气泡的浏览器测试 3 项通过。
桌面 1440×900、手机 844×390 实际自动预下载并命中缓存，无脚本错误。
隔离服务器双人 WebSocket 对局验证表情发给自身及队友，并回归加时、重连、准备开战。
ESLint 无错误，main.js 保留一条已有的无用 eslint-disable 警告。
完整旧表情浏览器套件另有两个已有断言失败：素材文件存在但清单不提供该 UI 精灵、晚挂载时间的精确字符串舍入；本次未将其计为通过。
