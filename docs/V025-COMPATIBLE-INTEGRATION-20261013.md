## 保留的定制内容

- 1–8 人房间、公开列表、招募、房间简介、公开／私有聊天、带简介的邀请链接。
- 分身／对战模式、可拖动聊天、横屏手机布局、反馈群入口、干员调配和自选编队。
- 克莱门莎沿用本地稳定 ID `chess_char_4_27_a/b`，商店档位为五本，三个盟约为阿戈尔、迅捷、不屈；特质阈值保持当前普通 3 杀、精锐 2 杀，仅给她所属且已激活的盟约加层，联防不触发。
- 当前装备不限库存、练度与养成规则、五至八人平衡和现有部署方式。没有引入上游前序版本的整套练度／潜能和装备限额规则。
- 现有 R2 路由、热更调度、对局隔离和最近调整的资源预加载行为。

## 验证结果

- 本次涉及的测试文件运行结果：1,143 项，其中 1,140 通过、1 项跳过、2 项失败。
- 两项失败均在更新前存在：`kits_t4.test.js` 写死干员数量 26，现有定制注册数为 27；`playtest3.test.js` 的旧断言禁止等待鼠标样式。对应战斗行为测试通过，未为了消除断言而改变当前定制行为。
- 新接入功能、卡池记账、场景资源打包的专项测试已经通过；房间协议、R2 回退、随机配对、伤害数字等兼容检查 110/110 通过。
- 实际浏览器检查：13 张地图 × 3 种外观 × 3 种视角，共 117 项通过，另检查 WebGL 不可用时的经典棋盘回退。场景资源未引发页面异常。
- 实际双客户端房间检查通过。覆盖公开／私有、房间简介、招募、聊天、复制邀请、三种外观和八人房流程；横屏尺寸包括 844×390、932×430、667×375、640×360。
- 补充真实开局检查：三种外观分别在普通、分身、对战模式中开局，9 种组合均保留所选外观。已修正旧对局构造器将新增官方外观重置成简约外观的问题；与房间和对战既有检查一起运行，20/20 通过。
- 源码导入边界检查通过；最终源码的主入口、对战入口和共享模拟模块构建成功。
- 随后追加的资源预加载提速通过 38 项专项检查和真实浏览器对比、暂停／进房／续下／刷新缓存检查，本地受控素材下载约快 2.03 倍。

完整测试库在更新前已有历史失败，本次没有宣称全库通过。相关日志、截图和每个应用文件的前后 SHA-256 均保存在 `outputs/v025-compatible-integration`。
