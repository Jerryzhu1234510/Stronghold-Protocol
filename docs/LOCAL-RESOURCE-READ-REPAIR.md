# 本地素材读取补修（2026-10-16）

已复现两个漏口：辅助页面在同一版本作用域注册了允许联网的Service Worker；安卓原生拦截器未去掉素材URL中的内容哈希目录。完整包拥有文件，不代表这两条读取路径一定会命中。

网页的各个入口现在统一选择本地资源策略。旧辅助标签页覆盖控制器时，已更新页面会恢复本地策略；训练场和对战辅助页也在启动前检查实际读取。普通浏览器里存在`chrome.webview`对象不再被误判成完整客户端。

安卓1.0.3在原生层统一解析普通地址和哈希地址，并保留音频Range读取。8443服内置素材未命中时不再回退下载大文件：核心素材明确失败，可选音频返回短静音。ICU服保留原资源策略。

旧完整资源包v2与0.2.5核心补全包继续有效。PC无需更新；网页玩家打完旧局后，从选服大厅重新进入。安卓1.0.3须由服主实际发布后覆盖安装，不要提前声称已上传群文件。

`tools/hot-resource-pages.mjs`提供成组的前端补丁：预先校验原文件哈希，将6个新JS模块发布到内容寻址的新地址，最后只替换5个不缓存的HTML入口。原模块、运行中的worker、固定账号服务与代理均保持运行；生成HTML备份和回退记录。它不清理旧对局，不占用新的游戏版本名额。

验收包括真实对局在前端替换后继续响应、Edge双页面覆盖缓存策略的复现、控制器恢复无循环，以及APK实际文件上的Java拦截器测试。Java测试使用Android API适配器，不代表真机WebView验收；仍需真实安卓设备确认。已打开的旧页面和未更新的APK可能继续请求素材，修复后的总带宽要结合新一轮采样判断，不能承诺立即归零。
