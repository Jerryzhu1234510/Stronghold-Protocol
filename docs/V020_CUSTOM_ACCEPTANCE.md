# v0.2.0 定制整合本地验收

本轮保留官方 v0.2.0 的新版干员、自选编队、补位、技能与模组、快捷键及语言功能，并恢复已有服务器定制。暂未上传腾讯服务器或推送 Gitee。

四人及以下使用新版联防地图；5～6 人使用双人联防和原倒计时；7～8 人使用原三人联防传送门及 1.6 倍倒计时。多人卡池、生命、干员属性、敌方难度、商店、禁用数量和有限重复开局都按选择的房间容量计算，额外加成不应用于四人及以下或单人模拟。

手机修正版：接上盟约倾向的页面请求；冻结、刷新及剩余角色数恢复原布局；盟约倾向缩小为右上角的独立控件。镜头按商店实际高度给候补区留空，拖动期间商店和倾向控件不接收指针。切换倾向只影响下次刷新，不额外扣费。

丰川祥子和结城理加入新版个人自选库存，共 73 名可选六星。此前四个外援槽位的本地设置会迁移到自选编队，已有新版自选设置优先。结城理三技能主动仅切输出替身，替身受到致命伤自动进入治疗形态，计时结束播放回本体动画。

验证：关键验收套件 544 项全通过。覆盖完整八人流程、五种房间容量、三人联防各地图地面/飞行路线、模拟与页面倒计时、个人库存及晋升奖励、24 种联动干员自选技能组合、旧配置迁移、整队匹配、页面导入、技能切形态、热更新隔离和旧对局保留。额外 131 项回归通过，涉及随机操作、联机帧同步、旧版带宽优化、其他干员与特效。

全量初筛曾运行 5234 项，5148 通过、69 失败、17 跳过；其后修复了实际接口与代码问题，并重新运行相关回归。原版生成数据、固定 71 人、原版盟约归属、语言文字、资源清单及历史快照的严格校验仍与定制包或本机工具环境有差异，因此不宣称整个上游测试套件全通过。详细结果在本验收目录的测试记录中。

热更保留每个版本的独立服务进程。旧对局继续旧版本，结算返回大厅后加载新版本。此轮不保证服务器重启或崩溃后恢复，也未对腾讯 200 人实测负载作容量承诺。

本轮追加验证：手机操作与联防规则相关 86 项通过；首领相关回归 82 项通过，另新增 48 项多人首领运行测试通过。新增测试覆盖 5/6/7/8 人、全部 10 种首领、真实客户端模拟、奇数人数落单席位、单一血量池、合并生命、失败结算和胜利通知。40 个首领入场测试使用完整生产血量；4 个胜利流程测试只在测试内降低首领血量，用于迅速验证击杀和全员结算，不代表实战平衡验证。

热更真实对局演练：旧版战斗中启用修正版，新入口立即使用修正版，旧连接和旧资源仍保留；旧玩家断线重连后继续同一局，进入后续回合并在第 4 回合自然结算。没有强制结束对局，也没有使用假战斗。前端另做浏览器实战验收，检查旧局更新提示及结算返回大厅时的版本切换。

v0.2.1 已单独下载源码并检查更新，尚未合并入本包。官方的满潜能、召唤物回合增益、加载期间接管/结束消息等改动需要与定制数值及三人联防一并适配，不能直接覆盖官方更新包。当前多人首领测试结论适用于本修正版 v0.2.0。

`npm run build-data` 会在官方生成后重放 `data/custom-overlay.json`，保留两位联动干员、指定盟约及语音资源；不要只运行官方生成器后直接发布。

本轮商店原布局调整：盟约倾向移动到右上角计时区内的独立小控件，手机756×366实测154×32像素；冻结、刷新、剩余部署数恢复原布局。相关56项测试、HUD回归10项通过，导入边界检查通过。浏览器实测核心/小盟约选择、刷新扣费、冻结/解冻、两次点击购买、候补部署/撤回和朝向确认，无运行错误。

新增服主指令入口deploy/hot/serve.mjs及Docker配置；通过真实旧局战斗中输入update、断线恢复、后续回合、自然结算、新版八人大厅、错误目录失败保持当前版、启动目录记录及计划重启后加载已记录版本的测试。启动记录不是对局存档。完整首次安装及日常热更流程见docs/热更操作流程.md；Docker配置尚未在腾讯运行，第一次安装需要维护。

屏幕缩放追加修正：商店避让区域使用控件高度而非动画期间的临时纵坐标，响应窗口变化时在下一帧及商店尺寸变化后重新计算镜头。浏览器复测桌面尺寸切回手机尺寸，布阵区域正常显示；最终相关回归 66 项通过。
