# v0.2.1 r10 休整加时

合作休整阶段提供“申请加时”30秒或60秒。每回合最多发起一次；发起者自动赞成，10秒内超过半数有投票资格的真人赞成才通过。原休整倒计时持续运行，投票不会暂停倒计时，也不会阻止全员准备立即开战。已经准备的发起者需先取消准备。早期回合原有准备时间保持不变。

资格在投票发起时固定：在线、存活且没有退出的真人；AI和旁观席不计入。断线不降低通过所需票数，重连保留投票和已投状态，原有资格的玩家可在投票时限内投一次票。未投票在到期时按拒绝处理。到达休整截止时间的迟到消息不能加时。

头像旁显示发起、赞成、反对或待投票。准备提醒为文字提示，不更改队友的准备状态；整队每5秒最多一次。投票面板只在申请或投票时展开，避开右侧效果栏和底部商店。

合作联防的模拟上限与服务器倒计时同时增加10%；7～8人房继续保留原来的1.6倍时长、三人联防及传送门。结算扣血规则不变。没有加入跳过战斗。
