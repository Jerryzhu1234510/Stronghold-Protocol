# 素材本地缓存验收

本地地址：http://localhost:3229/ 。点击设置，在下方查看“素材本地缓存”。首次进入只按需下载用到的素材，刷新后查看复用次数和减少下载的估算值。缓存默认开启，容量按当前版本全部可缓存素材的未压缩总大小自动设置（按整 MiB 向上取整；此版约686 MiB），不再固定256 MiB，可关闭或清空。

仅缓存同站点清单中图片、音频、字体、Spine骨骼和图集，不缓存HTML、JS、游戏数据、接口或WebSocket。每个热更版本有独立服务工作线程作用域；文件以SHA-256内容哈希共用缓存，相同素材跨版本复用，修改素材重新下载。旧版本按自己的清单取旧素材，不触发强制刷新。音频Range请求支持本地206响应。

首次下载、未命中素材、对局同步和服务器计算压力仍然存在。此功能不保证消除游戏延迟，也不代表已经接入CDN。不支持缓存的浏览器、HTTP公网网址或存储空间不足时继续正常联网加载。正式站需要HTTPS；本地localhost可测试。

清单由每个新版本服务器第一次请求时异步生成，四个文件读取任务并发，随后在该版本进程内共用，不会为每个玩家重复扫描素材。JSON清单使用gzip传输。约12,868项、686 MiB素材，当前本机生成用时约4.5秒。生成期间不拦住游戏素材请求；首批素材可能在下一次使用时才进入缓存。

已通过：资源缓存及热更9项回归测试；浏览器模块、兼容性和快捷键359项测试；导入边界检查。实际浏览器刷新后显示复用2次素材、减少下载约2.2 MiB；查看、关闭和恢复开启已操作验证。这个数值是本地素材命中的效果，不能推算整个服务器带宽降低比例。

当前仍为本地验收，没有替换腾讯服务器。旧r02多人选卡修复包没有包含这个新功能，不要将它当作缓存更新包。
