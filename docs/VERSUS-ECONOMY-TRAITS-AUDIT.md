# 对抗测试版：经济与特质检查

## 已落实

- 每段前四分钟每两秒一金币，此后每秒一金币，余额上限一百；守方击杀每只怪物固定一金币，攻方每击倒守方干员或每次漏怪造成蓝门扣血获得五金币。
- 升本费用 10/18/28/40/55，间隔二十秒；守方升本有部署人数要求，攻方没有。
- 升级保留现有卡和已售出格，防止把升级当作免费整店刷新。
- 攻守角色经济独立。第一段赚的钱不能在交换后直接用另一个角色的商店。
- 原战斗特质继续由原战斗引擎触发：攻击、技能、击杀、死亡、异常状态、弹药、部署等事件不是取消了。
- 简单的原回合开始/结束加层类，改为己方击杀对方投放怪物触发。只对已激活盟约加层，全部上限二百。
- 补上“已激活最高层盟约”和“不同盟约分别加指定层数”；位置类加层同时包含自己及实际朝向对应的邻格，不再固定只看左右。
- 已接入的金币特质额外击杀收益全队共享四秒冷却；免费刷新最多存两次，共享二十秒冷却。
- 已确认按三十秒统计窗口适配：获得干员数、主动刷新数、实际消费；免费刷新计次数不计消费，升本计消费，被动收入和击杀收入不计消费。
- 同行人数、不同阶人数、整备区人数和整备区盟约加层等复合条件每三十秒结算一次，不再按每次击杀重复结算整段消费。
- 随机制造装备、赠送干员、奇数窗口赠送、当前人数最多盟约赠送，使用原服务端处理器和原卡池权重；保留部署及同行人数条件，禁用干员不从奖励卡池发放。
- 售出特殊招募沿用原版免费选择界面；复制和触发前方干员沿用原版朝向、目标筛选与六层递归保护。定时复制每三十秒触发，售出和获得类按真实事件触发。
- 获得/售出后“下回合返钱”记为有限的待领取击杀奖励，原数量分多次兑现，每次一金币，共享四秒冷却。不退款，不变成永久的每杀额外收益。
- 三本及以前每包两只，四本起每包一只；源石虫整包三金币，杀完奖励两金币。前期怪物降价，次数怪衍生物不单卖。生命和攻击成长均封顶两倍。
- 商店每级扩容至最高十个干员或怪物位，守方另一个装备位；每次晋级从二十金币和一本重新开始，清空上一轮库存与角色银行。
- 攻守交换或新比赛段开始清空本段统计和待领取击杀奖励；整备和已结束对局不推进统计窗口。窗口内获得的赠送干员按真实获得数计入下一窗口。
- 原版“两只合成”的干员也使用原合成数量，不再一律要求三只；合成仍发原版选择奖励，不触发死亡。
- 盟约之币等即时消耗道具用原版处理器，不占装备格。随机 Ban 的盟约在统计、加层条件和战斗中都不激活。
- 对抗阿戈尔不吞噬，保留原生命加成并每层额外增加 0.5% 攻击和生命。每名在场成员每五秒增加一层，多人独立计时，使用真实时间，不受二倍战斗速度影响；备战区、倒地、隐藏不计时，撤回和倒地重置部分进度，上限二百。五名不同成员时前三名首次倒地立即复活规则保留。
- 角色和怪物详情复用原版实时数值面板，读取当前生命、属性、攻击范围和沉默状态；规则按钮及阿戈尔盟约说明同步当前规则，正常模式说明不变。

## 检查发现

本次已接入角色数据中的服务端特质处理器，人物详情显示实际的三十秒或击杀触发规则；原战斗特质仍走原战斗引擎。不是恢复旧回合，也不会打断八分钟攻守计时。

仍需继续核验的原型范围：复杂盟约的全部联动，以及持续回合、变换干员等特殊道具。未支持的持续/变换道具会明确拒绝使用，不消耗，也不当作普通装备静默装上。角色赠送道具与道具本身的适配是两个独立环节。

人物移动不重新创建战斗单位，保留生命、技力和已有战斗状态；撤回后重新部署的首次触发额度仍需逐一检查，不能当作全部已验证。

经济和交互测试不等于真人数值平衡已完成。金币独立分角色保存、源石虫不再倒送钱、升本不免费刷新，以及消费不重复结算，均已落实；不同强怪的长期攻守收益仍需要真人验收。
