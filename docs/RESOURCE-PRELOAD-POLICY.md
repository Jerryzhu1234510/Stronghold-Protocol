# 8443服联网预下载

8443服使用玩家导入的网页资源库或PC／安卓客户端内置素材，因此关闭游戏内的联网批量预下载。这个开关与“是否需要浏览器本地读取控制器”分开：原生客户端不需要网页ZIP，但同样不能启动批量下载。

界面显示“内置素材”或“本地素材”，保留状态检查、已有缓存读取和网页ZIP导入；不显示“资源预加载／继续预加载”。客户端设置页不再引导玩家下载或清空已有素材。旧完整资源包v2＋0.2.5补全包继续有效。

启动器在创建定时任务前拒绝预下载，底层`resourceCacheAction('warm')`直接返回禁用，worker也根据8443域名或`noPreload=1`拒绝旧页面发来的批量命令。其状态查询不扫描全库或下载完整素材清单。原生客户端正常游戏的本地拦截器仍可服务素材，网页的localOnly读取与缺失资源处理保留。

前端热补采用新文件地址。网页版保持原有`worker.js?localOnly=1`身份，避免同一作用域的新旧页面互相重注册；内置资源客户端使用新的禁止预下载worker，发现旧注册覆盖后恢复。发布worker位于版本根目录，注册地址需显式带上当前`/_build/<版本ID>/`前缀，使用默认作用域覆盖完整版本，并保留原资源目录基址、缓存分片与兼容补丁。不能依赖网关自动改写裸`/worker.*.js`地址。HTML、运行清单和部署代码清单必须同时更新，确保下次网关启动仍能通过完整性检查。

仅更新服务器下发的网页程序，无需重新分发EXE、APK或资源包。正在进行的对局继续运行，玩家打完后重新进入以加载修复；未刷新的旧页面无法仅靠修改服务器文件立即替换内存中的程序。本策略不改icu服或本地开发服务器的下载功能。

验证覆盖43项相关测试、真实Edge浏览器缓存与worker流程、PC／安卓用户代理，以及旧注册恢复。复现中旧PC路径手动预下载会拉取2个未缓存测试文件；修复后PC、安卓1.0.2/1.0.3与网页均为0次素材回源，网页已有内容命中缓存。这些模拟不等同真实安卓设备验收，也不能单独证明历史全部带宽来自预下载。
