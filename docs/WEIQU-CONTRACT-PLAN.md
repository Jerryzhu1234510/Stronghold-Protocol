# 卫区合约：独立模式计划

状态：2026-10-16 已确认方向，尚未实现；不是 0.3.0 兼容候选的已完成功能，也不代表正式服已经开放。

## 模式定位

卫区合约作为自带的独立模式入口开发，内部将合约目录、效果执行、房间确认和结算分开维护。玩家无需另装玩法插件。保留原有普通模式；选择卫区合约后，进入专用选约流程。

当前设计表共 58 组合约、136 个档位，数值为策划建议，仍须逐项实现与平衡；该数字不表示这些合约已经可用。合约用“目标：…”“源石环境：…”“环境：…”“反制：…”“协同战术：…”等危机合约风格拟名，档位用Ⅰ／Ⅱ／Ⅲ；这些是本模式拟名，不宣称为官方名称。

## 已确认的共同规则

- 全队共用一套合约；房主选择，所有真人玩家确认。房主修改后，旧确认失效；开局后锁定。
- 每个合约档位分配合约分；同组合约只能选一个档位。分数与合约数量分别展示。
- 每选择 4 个有效合约，结算额外增加 2 杯；同组升档不重复增加合约数量。
- 纯支援合约 0 分，不计入额外杯数的合约数量。原本纯正面的方案补上明确负面代价后，再按实际风险评估。
- 选择界面应显示名称、档位、效果、代价、分数、互斥与前置；避免通过互斥或不可生效的条目凑数量。
- 结算增加合约计分界面，逐项列出合约分、有效合约数和额外杯数；账号杯数只由服务器结算，并按对局去重。

## 仍待确定或实测

基础杯数与合约额外杯数在现有自定义减半规则中的先后顺序，仍按设计表待定项确认；部分特殊 Boss、死亡计数与无尽模式的适用范围尚未最终确定。不能在实现时悄悄把待定建议当成已确认规则。

首批优先做可独立验证的敌人属性、经济／招募限制、部署与场地限制。特殊 Boss、无尽、复杂联动和交换型合约随后逐项加入。默认关闭全部合约，并验证关闭模式时不改变普通模式。

## 服务器插件边界

用户确定：服务器插件只能由服主安装，向全服房间提供。房主选择服主已安装的玩法；普通玩家不能上传、安装任意服务器玩法或决定服务器结算规则。本地外观／音效 Mod 不因此获得修改玩法的权限。

卫区合约走自带模式；第三方插件未来是否可添加合约、是否计分计杯需另行设计。本次没有开放此类扩展。当前本地 0.3.0 启动器仍默认关闭服务端插件、工作台与脚本，不能把本文件当作已开放联机插件的说明。
