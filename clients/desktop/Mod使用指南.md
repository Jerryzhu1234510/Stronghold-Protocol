# 玩家指南：安装、切换和恢复外观／音效

适用于Windows PC客户端的8443服。外观／音效候选需要1.0.2及以上；生命归零事件音乐需要1.0.3及以上；包含自身归零需要本次更新的1.0.3及以上；20种通用音乐触发器和同包多事件需要PC 1.0.4；整局常驻音乐与角色跳动／旋转／翻转需要PC 1.0.5。只改变自己电脑的外观和声音，朋友使用他们自己的设置。网页、安卓和icu服暂不接入这个Mod系统。

## 安装

1. 完整解压客户端，运行“卫戍协议.exe”。
2. 顶部选择“Mods → 导入外观／音效 Mod ZIP…”，选择作者提供的ZIP。不用解压Mod或修改游戏文件。
3. 确认包名、版本、固定替换数量、新增候选数量及音乐事件数量，点击“安装并启用”。
4. 外观／音效候选默认启用作者推荐项，未指定时使用第一项。结束当前对局后按Ctrl+R，更新已经载入的素材。音乐事件安装后立即监听，已经发生过的事件不会补播。

PC 1.0.5的常驻音乐与视觉动作配置在兼容的当前对局可即时生效，停用时也即时恢复；素材替换仍按上面的重新载入方法使用。先安装程序更新包，再通过Mods导入新格式包，单独导入Mod不能升级程序。

升级首次启动会自动刷新HTTP脚本缓存，账号、本地存储、Mods和本地资源库保留，不用手动清数据。

更新同一个Mod时直接导入新版ZIP。同ID旧包会被替换；已有选择仍存在时会保留。“资源增量包”请用资源菜单导入，格式与Mod不同。

## 添加和选择多套外观或音效

新版包可以在保留原版的同时添加多套本地候选，例如同一干员的两套替代外观、几套攻击声音。

打开“Mods → 外观／音效选择 → 包名”，再选外观组或音效组。每组同时选一个选项，不同组可以组合。设置后重新载入。

候选显示在客户端顶部菜单，**不会添加到游戏内置皮肤列表**。新增外观候选须对应已有素材位置；新干员、技能和服务器公共皮肤需要另做游戏功能。

## 事件音乐Mod

事件音乐与普通Mod用同一个导入入口，支持下列触发方式。

“玩家生命值归零”：读取玩家头像旁的生命值，由正数降为0时播放音乐。作者可设置是否包含自己（需本次更新的PC 1.0.3）；附带的雨爱Mod已包含自己和AI队友。单个干员倒下、暂计的漏怪伤害、普通离开房间均不触发。合作模式生效，对抗模式和旁观席不触发。

同一玩家每局只触发一次；重复同步、进房时已经淘汰、重连后收到旧状态不会补播。多名玩家同时归零只选一种已配置音乐，不叠加、不排队；正在播放时是否切歌由下文固定优先级决定。AI是否计入由作者设置。

“对局开始”（需PC 1.0.4支持补丁）：正常开始一场新对局时播放一次，普通回合切换不触发；刷新、断线重连、中途进入已有对局不补播。下一场新对局可以再次播放。

PC 1.0.4还统一支持以下通用触发器：新回合开始、战斗开始、Boss战开始、联防战开始、休整期开始、本轮结算、回合胜利、回合失利、整局胜利、整局失败、整局结束、低生命值、自己生命值归零、队友生命值归零、本人6人／9人核心盟约战斗开始、本人叙拉古专属真伤效果触发，以及本人谢拉格干员冻结与谢拉格盟约冻结。具体触发器和音乐由Mod作者选择，旧客户端需先安装支持补丁；仅导入音乐包不能补上客户端能力。低生命值使用作者指定的绝对LP阈值，默认5点，并非百分比。

“本轮结算”在亲历普通战斗进入结算时触发，不区分输赢；“回合胜利”指本人本轮最终没有损失LP，“回合失利”指本人本轮最终损失了LP，使用服务器结算而非战斗中的预计漏怪数。Boss战不算普通轮结算。整局胜负采用正式结果页的团队结果，已淘汰玩家也可以随团队获胜；退出房间、断线或隐藏核心局部失败不会被当成整局失败。重复结果不会反复播放。同一时刻命中多个事件时，客户端按内置优先级选择一个，不会同时叠播多首。

核心盟约触发器在战斗开始时检查本人部署中的干员：同一核心盟约至少6人或至少9人，9人事件优先。同一基础干员不重复计算；整备区、队友、不同盟约、调和与策略虚拟人数不会凑在一起计算。

叙拉古特殊触发器读取当前本人战场正在播放的叙拉古专属真伤效果标记，其他来源的真实伤害或队友战场不算。它表示专属效果被触发，后续受护盾或免疫影响时，敌人HP未必下降。客户端统一2秒节流，不能由Mod自行去掉冷却，也不保证每2秒重播。

一个包可配置最多32项不同事件，同一事件不能重复；启停整个包时一起启停。也可以拆成不同包分别启停。同一种事件仍只播放优先级最高的一个包，不同事件各自计算优先级。普通同步、刷新和重连不会补播过去的生命周期事件。旧版生命归零Mod仍可继续使用。

谢拉格干员冻结与谢拉格盟约冻结为两个独立触发器，分别采用2秒节流；只统计当前本人战场中目标真正新进入冻结。只有寒冷、免疫、延长已有冻结或刷新时已冻结不触发。“干员来源”也可能包含该干员携带装备造成的冻结，不能继续细分为技能、天赋或装备。该接口适配0.2.5本地模拟，已核验当前8443模拟源码；客户端源码校验不匹配时安全停用，后续游戏版本需重新验证。它们与叙拉古特殊触发器同级，同帧命中多种时按客户端固定稳定顺序选择一个。

同一帧只选已配置事件里优先级最高的一个，顺序是：整局胜负 → 整局结束 → 自己归零 → 队友归零 → 低生命值 → 9人核心盟约 → 6人核心盟约 → Boss → 联防 → 叙拉古真伤效果／谢拉格两类冻结 → 回合胜负 → 本轮结算 → 普通战斗开始 → 对局开始 → 回合开始 → 休整期开始。

高优先级音乐可以打断正在播放的低优先级音乐；相同或更低优先级的新呼叫忽略，不排队、不叠播，也不重新从头播放当前音乐。安装顺序只影响同一种事件由哪个包提供音乐，不改变上述事件优先级。

打开8443服后，可使用“Mods → 试听音乐 Mod”试听，“Mods → 停止音乐 Mod 播放”立即停止。试听采用优先级最高的已启用事件音乐包。若浏览器内核尚未允许播放，先在游戏页面点击一次；真实触发时可等待下次点击／按键解锁，最多保留30秒，超时不补播。

音乐跟随游戏“背景音乐”音量及静音设置；设为0或静音时，事件不会补播。播放期间暂时压低原版BGM，音效与语音继续播放；结束、报错、停用或离开对局后恢复原版BGM。音乐文件从本机读取，不从游戏服务器下载。

## 整局常驻音乐（PC 1.0.5）

作者可以制作format:4常驻音乐包。它在对局期间持续循环，进入结算、离开房间或停用时停止；重新连接当前对局可以恢复。与“开局只放一次”不同，它用作整局背景音乐，不能把两种音乐的重连行为混为一谈。刷新或重启客户端不保证保留原来的准确播放秒数。

生命归零、Boss等事件音乐可以临时插入：常驻音乐暂停并保留位置，事件曲结束后再从原位置继续。静音或背景音量设为0时暂停，恢复音量后可续播；刚开始就静音时不会先创建播放中的音频。

若内核拦截首次自动播放，在游戏页面真实点击或按键即可解锁；常驻音乐会持续等待到解锁、停用或离局，不受一次性事件音乐的30秒等待限制。

主动选择“停止音乐Mod播放”后，常驻音乐本局保持停止；明确重新启用／切换常驻包或下一场新局可恢复。普通音量改变不会自行取消这次手动停止，之后新的事件音乐仍可正常触发。

常驻音乐同时只生效一个包，最后安装或从停用重新启用的包优先，重启会记住该顺序；停用最高优先包后可以回退到其它已启用包。它不改变旧事件音乐包的安装优先级。所有音频仍从本机读取。

## 干员视觉动作（PC 1.0.5）

format:4还可以让干员在本机显示跳动／旋转／翻转。作者可选择仅本人干员（own），或包含自己和队友的己方干员（allies），不影响敌人或召唤物。可调跳动高度、频率、旋转速度；flipX控制左右镜像，flipY控制上下翻转，均为true／false且默认false。只翻转而不跳动、旋转也可制作，附带示例默认不镜像或倒立。不改变部署位置、移动、朝向逻辑、攻击、射程、命中或伤害，朋友不会因此获得任何玩法变化。

这些效果可以一起开启。例如作者在mod.json里使用下面的motion，就会每秒跳一次、视觉转一圈，并叠加左右镜像：

```json
"motion": {
  "target": "own",
  "bounceHeight": 0.3,
  "bounceHz": 1,
  "spinRps": 1,
  "flipX": true,
  "flipY": false
}
```

在参数合法范围内，spinRps等于bounceHz时一跳转一圈，取负值时反向；要这样同步时bounceHz不超过2。flipX／flipY是可同时叠加的静态开关。附带示例是一秒一跳、一跳一圈的视觉动作，高度0.3，两个flip默认false；需要不同效果时由作者改清单并重新打包导入。

动作配置只生效一个包，最后安装或重新启用的包优先，不按不同目标叠加。停用、移除或替换后即时恢复原来的视觉状态，不需要重下载素材。离房或结算也会停止应用；遇到未经适配的游戏渲染版本时安全停用动作接口。

常驻音乐和动作是两个新配置接口，原来的20种事件触发器仍然保留；同一个包可以组合音乐、动作、外观候选与事件音乐，也可以分别制作成独立包。

## 恢复和删除

- 停用候选组：选择“使用原版（停用本组选项）”。其他包或本包固定替换若仍作用于同一素材，它们继续生效。
- 停用整个包：取消Mods菜单中包名前的勾选。音乐立即停止并停用；已经载入的固定替换和候选重新载入后恢复。
- 删除整个包：选择“Mods → 移除外观包 → 包名”。内置资源不会被删除。
- 冲突优先级：后安装的已启用包优先；同包中所选候选优先于固定替换。停用高优先级包后，下一个包或原版恢复。
- 同一音乐事件同时安装多个包时，也按后安装的已启用包优先，只播放其中一个。

## 支持范围

头像、立绘、兼容的战斗小人、图片、音效、语音、BGM、字体及客户端明确支持的事件音乐。Spine小人通常需成套提供SKEL、ATLAS与纹理，结构不兼容会显示异常。Mod不能随意定义新的音乐触发条件或执行脚本。

不会执行Mod脚本或更改游戏数值、技能、盟约、商店和联机规则。icu服和安卓暂不启用此入口。

## 没有效果时

1. 确认PC进入8443服，包已勾选、候选已选择，之后按Ctrl+R。
2. 进入实际使用该素材的位置；关闭的音量或未触发的技能不会播放声音。
3. 查看“Mods → Mod状态”：命中数表示素材被请求，校验失败表示已安装文件损坏，可重新导入。
4. 服务器更新导致原始哈希变化时，旧映射自动跳过，请作者更新适配。字体或Spine结构错误也需作者修正。
5. 停用整个包并重新载入，检查原版是否正常。

正式资料位于 `%APPDATA%/WeishuDesktop8443/mods`；本地房间扩展测试独立保存于 `WeishuDesktop8443-LocalExtensions/mods`。菜单可打开实际文件夹，不建议手改注册文件。

## PC 1.0.8：本地 Mod 预览室

从客户端顶部“Mods → 本地 Mod 预览室”打开独立窗口。无需连接游戏服务器，也不会退出主窗口正在进行的对局。选择“当前启用组合”可检查实际生效的音乐、动作和图片；选择单个包可预览未启用包及所有候选素材，不会修改正式勾选或候选设置。

- 20 个音乐事件逐项试听，包括 Boss 战、同核心盟约 6/9 人、叙拉古真实伤害、谢拉格冻结；未配置的事件置灰。试听使用包内真实音频、起播位置及音量。
- 整局 BGM 可以开始循环、停止；事件音频播放完后恢复循环。预览音量只影响预览窗。
- 选择内置干员立绘或已安装包的图片，检查原图对照、跳动、旋转与横向/纵向翻转。动作复用游戏的 2D 接口；这里是图片预览，不拼装 Spine 骨骼。完整小人外观需要在训练场实际部署后验证。
- 音效替换项也可以直接试听。骨骼、图集和字体列出清单供核对，不作为普通图片解码。
- 点击“停止全部声音与动作”或关闭窗口可停止预览。导入或切换包后，点击“刷新已安装包”更新列表。

本地训练场位于顶部“游戏 → 本地训练场（独立窗口）”，需要先运行本地兼容测试服的“启动房间扩展本地测试服.cmd”。训练场使用真实模拟与渲染检查配装/皮肤；预览室试听跳过触发条件，所以“能试听”不等于游戏里的事件条件已经满足，最终仍需验证对应战斗触发。以上功能仅限受控本地 Mod，不开放脚本和联网玩法 Mod。

训练场也支持已启用的受控音乐和小人动作：开始训练后播放循环 BGM，按所选战场触发开战／Boss 音乐，并观察真实战斗事件（如叙拉古真实伤害、谢拉格冻结）。暂停、页面切到后台、训练结束或离开时停止播放与动作，继续训练不会重复播放 Boss 开场曲。训练使用独立本地状态，不连接正式房间；队友生命、联防和整局胜负等未模拟的事件请使用预览室试听，再在对应正式玩法中验证触发条件。
