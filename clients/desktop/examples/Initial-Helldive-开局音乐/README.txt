Initial Helldive-开局音乐 Mod v1.0.0

适用：Windows PC客户端1.0.4及以上，8443服。旧客户端需先安装通用音乐触发器程序更新包。
音频：用户提供的 Wilbert Roget II - Initial Helldive Theme.mp3，包内原样保留。

安装：
1. 关闭客户端，将PC 1.0.4程序更新包解压到“卫戍协议.exe”所在根目录覆盖。
2. 重新启动，打开“Mods → 导入外观／音效 Mod ZIP…”。
3. 选择 Initial-Helldive-开局音乐-Mod.zip，安装并启用。这个Mod ZIP无需解压。
4. 正常开始一场新的对局，音乐自动播放一次。

普通回合切换不触发；刷新、重连或中途进入旧局不补播。离开后开始另一场新对局可再次触发。
音乐采用游戏背景音乐音量并乘0.8，静音或背景音量为0时跳过。只在安装者本机生效。
按客户端内置事件优先级播放，较高优先级事件可打断本曲，相同或更低优先级不排队叠播。
可在Mods菜单试听、停止、停用或移除此包；停用不会重新触发已发生的开局事件。
本包只有本地音频、清单与说明，不含脚本，不修改服务器、账号或游戏数值。
程序更新包用解压覆盖安装；本Mod通过Mods菜单导入。不要将它们当作网页素材包或PC资源增量包导入。
通用指南见 Mod使用指南.md；制作协议见 Mod制作指南-AI.md。
