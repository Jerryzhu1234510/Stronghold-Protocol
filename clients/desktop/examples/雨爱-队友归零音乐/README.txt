雨爱 · 生命归零音乐Mod
Mod版本1.0.2：音频为用户提供的“DJ.Lee - 雨爱.mp3”。已安装旧版时直接重新导入本ZIP，同ID自动替换。
适用于本次更新的PC客户端1.0.3及以后版本的8443服。此前已下载1.0.3时，请先覆盖最新版累计程序更新包。
导入：顶部Mods → 导入外观／音效 Mod ZIP… → 选择本ZIP → 安装并启用。
自己或任意队友（含AI）的玩家生命值从正数降为0时播放DJ.Lee版雨爱；单个干员倒下不触发。
每位玩家每局一次；重连、重复同步、初始已淘汰不补播。播放中再有人归零不会叠加或重启。
音乐跟随背景音乐音量及静音；播放时临时压低原版BGM，结束或停用后恢复。
试听／停止：Mods → 试听音乐 Mod／停止音乐 Mod 播放。
全局停用：取消Mods菜单中本包前的勾选。
通用教程见客户端根目录“Mod使用指南.md”，AI制作规范见“Mod制作指南-AI.md”。
音频由用户提供，本包未联网下载歌曲；请按音频的授权范围使用和分享。
